What I built

  • Faster access to 2.5 million rows. Delivered 19 self-scoped optimization tickets, using PostgreSQL tuning, materialized views, batched API endpoints and Redis caching to bring queries from 25 seconds to under 2 seconds.
  • Filtering that could grow. Refactored API and UI architecture with Builder and component-based patterns, expanding from three to 40+ cascading filters under a Q4 deadline, with tests and incremental retirement of older services.
  • More efficient application execution. Profiled memory use, fixed leaks and improved cache management. Added LLM caching and cross-region AWS Bedrock load balancing to reduce repeated initialization and throttling pressure.
  • Applications connected end to end. Delivered FastAPI and Streamlit applications with Microsoft Entra ID/JWT authentication, processing feedback, Terraform infrastructure and Azure Pipelines delivery.
