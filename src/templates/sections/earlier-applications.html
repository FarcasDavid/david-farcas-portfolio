Multimodal document OCR

OutcomeTurned PDFs and images into structured Markdown and Excel downloads through an authenticated API and an upload interface.

  • Extraction pipeline: Built pdf2image/Poppler conversion, multithreaded batched AWS Bedrock inference, result synthesis and output generation.
  • Extensible extraction: Designed modular prompts so new document use cases could be added without changing the core inference pipeline.
  • Usable delivery: Built FastAPI endpoints, JWT/Microsoft Entra SSO, presigned S3 downloads and a Streamlit interface with uploads and processing feedback.
  • Repeatable releases: Provisioned AWS infrastructure with Terraform and configured Azure Pipelines CI/CD with temporary environments.

AI-assisted vehicle listings

OutcomeSecured access to a vehicle-description assistant, reduced repeated authentication and model setup, and made vehicle inputs more tolerant of typing errors.

  • Protected access: Integrated frontend SSO and backend token validation for the FastAPI service.
  • Fewer external requests: Implemented JWT and long-lived token caching to reduce repeated authentication calls and memory use.
  • Reusable model setup: Cached LLM chains and model instances to avoid rebuilding them for each request and reduce application load.
  • More forgiving inputs: Built typo-tolerant matching for vehicle make, model and year inputs.

Workforce & sales assistant

  • Connected services: Managed environment configuration and Azure service connections for the application’s cloud services.
